# Merge PR

When the user asks to merge the pr follow these steps:

1. Search for the related issues and documentation regarding the pr(s) being merged.
2. Make sure those issues or docs are up to date before merging the PR. Documentation changes should be included in the pr being merged, ex: changelog, roadmap.
3. Merge the pr(s)
4. Give the user a status report once the pr(s) is(are) confirmed merged.

# Finishing up

Your final response should follow this format.

Issues closed: #ID <link>, #ID <link>, etc.
Issues still open: #ID <link> <status>, #ID <link> <status>, etc.
PR('s) merged: #ID <link>, #ID <link>, etc.
Whats Next: (use the land skill for this, keep it to bullet points and short sentences with the unslop skill)
