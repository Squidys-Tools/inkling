- **Note tile:** switches the dialog to a form with a `textarea[aria-label='New note']`. Focus lands in the field automatically.
- **Saving:** Enter submits. Shift+Enter inserts a newline, and an IME-confirming Enter is ignored. The `button.add-menu-save` ("Save to library") submits too.

## 1) Feature summary

- The field is `input[aria-label='Search your mind']`, rendered by `CaptureBar` through `SearchField`. At rest the input is in the DOM but visually hidden: width 0, opacity 0, with a pill showing the view name. On focus it expands, and the `esc to close` hint appears.
- `/` or Ctrl/Cmd+K focuses the field when the focus isn't in an editable target. `N` opens a new note.
- Typing updates `query` immediately. The backend search runs only after a 200 ms debounce. In the desktop app there is no client-side filtering (`canUseDesktopBackend` short-circuits it), so the grid changes about 200 ms plus IPC time after the last keystroke, not per keystroke.
- The backend (`search_items`) tries to embed the query. If the embedder is missing or throws, it returns null and the search falls back to lexical only.
- Lexical search is SQLite FTS5 over title, description, source_label, ocr_text, metadata and body. Each whitespace-separated token is double-quoted, so matching is whole-token with no prefix matching. `alp` does not match `alpha`. Results sort by `updated_at` descending.
- If FTS5 is disabled, it falls back to `LIKE` substring matching.
- Notes have a null title, so a note is found through `body`.
- Clearing works four ways:
  - Escape in the field clears the query and blurs.
  - While the field is unfocused and the query is non-empty, a "Clear search" × button (`aria-label="Clear search"`) appears in the pinned filter row.
  - Empty results show a "Clear search" text button.
  - Emptying the text restores the grid after the debounce.
- The pinned filter row (query chip, `.result-count`, "result(s)", "Save as Space") shows only when the field is unfocused and the query is non-empty.
- The empty-results state is a dashed panel with the heading "Nothing surfaced yet.", the text "Try another word, or save something new to your mind." and a "Clear search" button.
